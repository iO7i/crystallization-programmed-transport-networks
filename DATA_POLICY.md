# Data policy

This repository contains code, synthetic morphology fixtures, and generated benchmark outputs.

- No confidential university or laboratory data is included.
- No unpublished experimental data is included without explicit authorization.
- Imported raw experimental data, if added later, must be immutable and provenance-recorded.
- Public datasets must have documented reuse rights.
- Synthetic data must be labeled as synthetic.
- Reproduced published data retains the original attribution.
- Digitized literature data must record the extraction method and source figure.
- Earlier personal experimental measurements are not trusted reference data by default.
- Generated results must carry software, input, and environment provenance.
